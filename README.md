I am using Claude AI to make a terminal that works the way I want it to, and I started with Alacritty (an excellent terminal).

Mainly, what I want is tabs because I already use tmux in ways that I like, and what tmux is missing is tabs, or is it alacritty that's missing tabs? I want the option to keep all of my dozens of tmux windows in one X11 window that I can grab with one mouse click. I might want other things too, so this is forked and we'll see where it goes.
